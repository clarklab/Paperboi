PAPERBOI

a faithful Paperboy homage — and an experiment in how thin a game can be.

paperboi.c → clang → 11 KB wasm → deflate → this page

WHY THIS IS NOVEL

NO ENGINE. NO ASSETS.

One small C file compiled straight to WebAssembly with plain clang (--target=wasm32 -nostdlib). No emscripten, no libc, no framework — not one image, sound, or sprite sheet is loaded.

THE WORLD IS MATH

Nothing is stored. Each frame inverts the 2:1 isometric transform per pixel, so lawns, driveways, and lane dashes are arithmetic on world coordinates. Houses and cars are procedural boxes; the font is 15 bits per glyph.

JS HOLDS ZERO GAME LOGIC

JavaScript only blits the framebuffer, reads your finger, and beeps when the wasm raises an event bit. The module is embedded in this page as text — view source: that's the whole game.
